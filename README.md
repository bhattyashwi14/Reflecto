# Reflecto

A Java-based personal growth and productivity platform designed to help users reflect, organize, challenge themselves, and share experiences through a unified system.

Reflecto combines journaling, task management, challenges, and community interaction into a single application while demonstrating the practical implementation of Object-Oriented Programming, Data Structures, Exception Handling, and Database Management.

---

## Features

### User Authentication

- User Signup
- User Login
- Input Validation
- Database-backed Authentication

---

### Journal Management

Users can:

- Add journal entries
- Edit existing entries
- Delete entries
- Search journal entries

---

### To-Do List Management

Users can:

- Create task lists
- Edit tasks
- Delete tasks
- Search tasks
- Mark tasks as completed

---

### Challenges System

Users can:

- Browse challenges
- Add personal challenges
- Accept challenges
- Track accomplishments
- View completed challenges

---

### Community Posts

Users can:

- Create posts
- View latest posts
- Browse random posts
- View their own posts
